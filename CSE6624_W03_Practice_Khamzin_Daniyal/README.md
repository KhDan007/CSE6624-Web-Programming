## Concept Note: `src` vs `alt` (Defence Criteria)

- **`src` (Source):** Specifies the address (relative path or URL) of the image file to be fetched and rendered on the web page.
- **`alt` (Alternative Text):** Provides a textual replacement for the image. It is read by screen readers for visually impaired users and displayed if the image fails to load.
