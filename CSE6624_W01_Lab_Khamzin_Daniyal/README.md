## How to Run

1. Open the project folder in VS Code.
2. Right-click `index.html` and select **"Open with Live Server"** (or click **Go Live** on the VS Code status bar).
3. The page will open in your browser at `http://127.0.0.1:5500/index.html`.

---

## Deliverables & Features

- **Semantic HTML5:** Built using `<header>`, `<main>`, and `<footer>` tags in `index.html`.
- **External CSS:** Linked `css/styles.css` applying custom styling (background colors, typography, layout padding, button styling).
- **External JavaScript:** Linked `js/main.js` before `</body>`:
  - Logs `Week 01 lab script loaded` to the DevTools Console on page load.
  - Listens for a click event on the `#go` button to dynamically update the `#message` paragraph and log `Button clicked` to the console.
